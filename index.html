tcpo

跨境链路内核调优面板 · 纯 bash · 无依赖 · 可完整回退 Linux kernel network tuning for long fat networks · pure bash · no deps · fully reversible

Note: the panel UI itself is in Chinese.

bash <(curl -sL https://tcp.itssx.com/tcpo)

需要 root。首次运行自装到 /usr/local/bin/tcpo，之后敲 tcpo 即可打开面板。 Requires root. First run installs to /usr/local/bin/tcpo; type tcpo anywhere afterwards.

非 root 用户请先 sudo -i 切到 root 再执行。一条命令搞定：curl -sL https://tcp.itssx.com/tcpo | sudo bash。 Not root? Run sudo -i first, or use the pipe form: curl -sL https://tcp.itssx.com/tcpo | sudo bash.

离线安装 Offline install

脚本是单文件、无依赖，离线安装就是把文件传上去。先在能上网的机器下载： It's a single file with no dependencies. On a machine with internet, download it:

curl -fL -o tcpo https://tcp.itssx.com/tcpo

传到目标机并运行： Upload and run: 

# 传上去（把 root@1.2.3.4 换成你的机器）# Upload (replace root@1.2.3.4 with your host)
scp tcpo root@1.2.3.4:/root/

# 登上去运行（会自装到 /usr/local/bin/tcpo）# Log in and run (installs to /usr/local/bin/tcpo)
ssh root@1.2.3.4
bash /root/tcpo

本地文件执行时脚本不联网，直接复制自身到 /usr/local/bin/tcpo。装完就能敲 tcpo。 When run from a local file the script does not touch the network — it copies itself to /usr/local/bin/tcpo. After that, tcpo works.

离线机上菜单 7（在线更新）会失败——这是预期的，不影响任何功能。要升级就重复上面的流程覆盖一次。 On an offline box, menu 7 (online update) will fail — that's expected and affects nothing. To upgrade, just repeat the steps above and overwrite.

想彻底禁止脚本联网：TCP_DASHBOARD_NO_CHECK=1。 To disable all network calls: TCP_DASHBOARD_NO_CHECK=1.

标灰的 8/a/b 是只读功能，不装包、不改配置、不重启服务，生产机可以放心跑。唯一例外：菜单 a 里如果指定了压测对端且没装 iperf3，会问一次要不要装（压测会产生真实流量），答 N 就只做被动观测。 Greyed 8/a/b are read-only — no packages installed, no config touched, no services restarted. Safe on production. One exception: in menu a, if you name a peer to benchmark against and iperf3 is absent, it asks once (benchmarking generates real traffic); answer N and it stays passive-observation only.

菜单 i 关的是整个 IPv6 协议族，不只是解析顺序。这台机器只有 IPv6 入口时关掉就等于自断 SSH，所以执行前会检查当前 SSH 会话是否走 IPv6、有没有 IPv4 默认路由、出口网卡上有没有 IPv4 地址；信息不全（缺 ip、tmux 丢掉了 SSH_CONNECTION）同样直接拒绝，不给确认选项。它也不在菜单 9 的一键优化里。 Menu i disables the whole IPv6 stack, not just resolution order. On a box reachable only over IPv6 that would cut your own SSH, so it first checks whether the current SSH session came in over IPv6, whether an IPv4 default route exists, and whether the egress NIC has an IPv4 address. Incomplete info (no ip command, SSH_CONNECTION lost in tmux) is also a hard refusal — no confirm prompt. It is also excluded from the menu-9 do-everything run.

想先看看会改什么 Preview changes first

TCPO_DRYRUN=1 tcpo

演练模式，整个流程照跑但不写入任何文件，退出时告诉你它本来会改什么。不需要 root。 Dry-run mode: runs the full flow without writing anything, then shows what it would have changed. No root needed.

可以回退 Reversible

每次改动前自动备份原始值，菜单 6 一键还原到改之前的状态。最坏情况是「参数没生效」，不会让机器开不了机。 Original values are backed up automatically before every change. Menu 6 restores everything. The worst case is "the setting didn't take effect" — it will never break boot.

兼容性 Compatibility

支持 Debian / Ubuntu / RHEL / openSUSE / Arch / Alpine 六大系。写入类菜单（1-5、9、i）缺工具时自动安装，装不上会降级并说明影响；只读菜单（8/a/b）不主动装任何包，只提示手动补装命令（唯一例外是菜单 a 的 iperf3，会先问你一次）。sysctl 是唯一装不上就不做任何改动的依赖 —— 读不到原值就没有可靠回退。 Supports Debian, Ubuntu, RHEL, openSUSE, Arch, and Alpine. The writing menus (1-5, 9, i) install missing tools automatically and degrade if that fails; the read-only menus (8/a/b) install nothing on their own and just print a manual install command (the sole exception is iperf3 in menu a, which asks you first). sysctl is the one dependency whose absence aborts the change outright — without it there is no reliable rollback.
